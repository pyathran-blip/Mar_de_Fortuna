# Mar de Fortuna

**Mar de Fortuna v4** é um jogo HTML5 de pesca. O jogo pode ser executado no navegador e também está disponível como aplicativo Android para teste.

## 🎮 Jogar online

https://pyathran-blip.github.io/Mar_de_Fortuna/

## 📱 Baixar APK público para Android

**[Baixar Mar-de-Fortuna.apk](https://github.com/pyathran-blip/Mar_de_Fortuna/releases/latest/download/Mar-de-Fortuna.apk)**

- [Ver todas as versões (Releases)](https://github.com/pyathran-blip/Mar_de_Fortuna/releases)
- APK publicado: versão de teste gerada pelo GitHub Actions; não é uma publicação oficial da Google Play.
- Para instalar, baixe o APK no Android e permita a instalação de aplicativos dessa origem quando o sistema solicitar.

## ▶️ Jogar no computador

1. Baixe o repositório pelo botão **Code → Download ZIP**.
2. Extraia o ZIP.
3. Abra `index.html` em um navegador moderno.

## 📁 Arquivos principais

- `index.html` — jogo HTML5 (HTML, CSS e JavaScript).
- `app/` — projeto Android que carrega o jogo numa WebView.
- `.github/workflows/main.yml` — automação de compilação e publicação do APK.

## 🛠️ Compilação automática

O GitHub Actions compila o APK quando há alterações na branch `main`. As versões publicadas ficam disponíveis em **Releases**.
