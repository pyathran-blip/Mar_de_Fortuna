# Mar de Fortuna

Versão final do jogo Mar de Fortuna v4. Jogo HTML5 de pesca, executado diretamente no navegador.

## Jogar online
https://pyathran-blip.github.io/Mar_de_Fortuna/

## Conteúdo
- `index.html`: jogo completo (HTML, CSS e JavaScript integrados).
- `app/src/main/assets/index.html`: cópia usada pelo projeto Android, quando presente.

Para jogar localmente, abra `index.html` num navegador moderno. Para atualizar a página publicada, faça commit e envie as alterações para a branch `main`.
